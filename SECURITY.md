# Security Policy

## Supported Versions

The latest version of Log Analyser is currently supported with security updates and fixes.

Older versions may not receive security updates.

## Reporting a Vulnerability

If you discover a potential security vulnerability in Log Analyser, please report it responsibly.

- Open a GitHub issue for non-sensitive bug reports and general security concerns.
- For vulnerabilities that could expose sensitive information or be exploited by others, please avoid publicly disclosing technical details before a fix is available. Use GitHub's private vulnerability reporting feature if enabled for this repository.

Please include the following information where possible:

- A description of the vulnerability.
- Steps to reproduce the issue.
- The potential impact.
- Any suggested fixes or mitigations.

## Security Considerations

Log Analyser processes Apache and Nginx server log files. Users should:

- Only analyse log files from trusted or authorised sources.
- Avoid sharing log files containing passwords, access tokens, IP addresses, or other sensitive information.
- Treat log files as untrusted input and avoid processing files from unknown sources without appropriate precautions.

As this is a personal project, security reports will be reviewed on a best-effort basis.
