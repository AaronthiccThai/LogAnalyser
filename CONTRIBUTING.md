# Contributing

Thank you for your interest in contributing to Log Analyser!

Although this project is currently maintained by a single developer, contributions, suggestions, and bug reports are welcome.

## How to Contribute

1. **Report bugs** by opening an issue and providing steps to reproduce the problem.
2. **Suggest improvements** by opening an issue describing the proposed feature or enhancement.
3. **Submit changes** by forking the repository, creating a new branch, and opening a pull request with a clear description of your changes.

## Development Guidelines

- Follow the existing C++17 coding style and project structure.
- Keep changes focused and maintainable.
- Include tests for new functionality where appropriate.
- Ensure the project builds successfully before submitting a pull request.

## Questions

If you have questions or suggestions, feel free to open an issue in the repository.
